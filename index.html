Tab Agent

一只住在每个网页上的气泡小宠物。点击它提问，你配置的 Qoder 云端 Agent 会结合当前页面内容作答。

⚠️ 本项目非 Qoder 官方产品，仅基于 Qoder Cloud Agents 构建。

GitHub 仓库 中文文档 下载 Releases

问页面

点击宠物提问，可携带当前页面正文或截图一起发问，回答流式出现。

摘录

右键菜单或快捷键 Alt+Shift+S 保存选中文字为摘录，高亮刷新不丢、可跨页跳转。

多端支持

基于 WXT 构建，原生支持 Chrome（MV3）与 Firefox 扩展。

快速上手

  1. 从 Releases 下载扩展包，或克隆仓库执行 pnpm install && pnpm build。
  2. 在 chrome://extensions 开启开发者模式，加载已解压的扩展。
  3. 在设置页填入自己的 Qoder PAT / Agent ID / Environment ID。
  4. 打开任意网页，点击右下角的气泡宠物开始提问。

云端配置

前置条件：Node.js ≥ 22.13 与 pnpm；一个 Qoder 账号，且已开通 Cloud Agents。

扩展连接你自己的 Qoder 云端 Agent，需要以下凭证：

凭证格式从哪拿
PATpt-...PAT 生成页面 → 新建
Agent IDagent_...Cloud Agents 控制台 → 你的 Agent（请确保已接入 Notion MCP）
Environment IDenv_...环境管理页面 → Agent 关联的环境
Vault IDvault_...Vault 创建页面（接入 Notion MCP 的必要配置，存放 Notion OAuth 凭证）

填入方式：点浏览器工具栏的 Tab Agent 图标 → 齿轮图标（或右键图标 → 选项）打开设置页，依次粘贴 PAT / Agent ID / Environment ID（Vault ID 接入 Notion MCP 时必填），输入框失焦即保存。同页可切换语言与主题。

云端 Agent 的完整配置教程（模型、系统提示词、工具集、Notion MCP、环境与 Vault）见架构文档「本项目实例配置」章节。
